🐘 PHP Built-in Server (Tanpa Laravel / Artisan)

Gunakan perintah native PHP ini yang bisa dijalankan di folder mana saja tanpa butuh file `artisan`.

php -S localhost:8000
php -S 0.0.0.0:8000

🟢 Node.js & Vite Commands

Vite / Next.js membatasi akses network demi keamanan default development.

npm run dev
npm run dev -- --host 0.0.0.0

🐍 Python Server Commands

Server web praktis bawaan Python tanpa install library/framework tambahan.

python -m http.server 8000 --bind 127.0.0.1
python -m http.server 8000 --bind 0.0.0.0

🛠️ Pertolongan Pertama Error

Panduan Troubleshooting Masalah Umum

Temukan solusi instan untuk 8 masalah yang paling sering dialami developer muda.

❌

1. Localhost Tidak Bisa Dibuka

Penyebab: Server belum dinyalakan atau salah mengetik port di browser.

Solusi: Cek terminalmu, pastikan proses server masih running. Pastikan menulis port dengan tanda titik dua, misal: localhost:8000 (bukan localhost 8000 atau localhost/8000).

⚠️

2. Error "Port Already in Use"

Penyebab: Ada aplikasi lain (atau terminal lama) yang masih menggunakan port tersebut.

Solusi: Ganti nomor port saat menjalankan server (contoh ganti dari 3000 ke 3001), atau matikan aplikasi lama via Task Manager / Terminal.

🛡️

3. Terhalang Windows Firewall

Penyebab: Windows Firewall memblokir koneksi masuk dari HP demi keamanan.

Solusi: Saat muncul popup Windows Defender Firewall, pilih centang pada "Private Networks" dan klik Allow Access. Atau izinkan port tersebut di Inbound Rules Firewall.

📍

4. Salah Mengeset IP Komputer

Penyebab: IP local laptop berubah karena router memberikan IP baru (DHCP), atau kamu salah melihat IP interface (misal IP VirtualBox/VPN).

Solusi: Selalu cek ulang IP terbaru pakai ipconfig / ifconfig di terminal sebelum mencoba connect dari HP.

📶

5. Tidak Satu Jaringan WiFi

Penyebab: HP menggunakan Paket Data 4G/5G atau terhubung ke SSID WiFi yang berbeda dari laptop.

Solusi: Hubungkan kedua device ke nama WiFi yang persis sama. Jika di kosan/kantor WiFi diisolasi (AP Isolation), gunakan Hotspot dari HP ke Laptop!

⏹️

6. Server Belum Running / Inactive

Penyebab: Jendela terminal tidak sengaja tertutup atau ketekan Ctrl+C yang menghentikan proses server.

Solusi: Buka terminal baru dan jalankan kembali perintah penyedia server kamu.

🔒

7. Binding Hanya Ke Localhost (127.0.0.1)

Penyebab: Server dijalankan tanpa flag host binding, sehingga menolak koneksi jaringan luar.

Solusi: Tambahkan argumen binding ke 0.0.0.0 (misal: php artisan serve --host=0.0.0.0 atau npm run dev -- --host 0.0.0.0).

🌐

8. Bingung Menggunakan IP 0.0.0.0 di Browser HP

Penyebab: Memasukkan http://0.0.0.0:8000 secara mentah-mentah di URL browser HP.

Solusi: 0.0.0.0 hanya untuk konfigurasi SERVER. Di browser HP, selalu masukkan IP Local Komputer kamu (seperti http://192.168.x.x:8000)!
