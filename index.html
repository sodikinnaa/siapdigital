MODUL 01

Apa Itu Server & Localhost?

Tujuan

Memahami bahwa komputermu sendiri bisa menjadi "server" dan mengerti arti istilah localhost.

Penjelasan Singkat (Analogi Warung Makan)

Bayangkan Server itu seperti Warung Makan yang siap melayani pesanan kapan saja. Browser (Chrome/Firefox) adalah Pembeli yang minta makanan.

Istilah localhost hanyalah nama panggilan sayang untuk "Komputer Saya Sendiri". Jadi saat kamu mengetik localhost di browser, kamu sebenarnya bilang: "Hei browser, tolong ambilkan halaman web yang ada di laptop ini sendiri, bukan di internet!"

Diagram Sederhana

 [ Browser Kamu ] 
        |
  Minta: "localhost:8000"
        |
        v
 +-------------------------------------+
 | Laptop Kamu (Bertindak sbg Server)  |
 |  -> Aplikasi Web Melayani Pesanan  |
 +-------------------------------------+

Praktik (Jalankan Server Pertama)

Cobalah jalankan server web paling sederhana bawaan Python di komputermu:

  1. Buka Terminal (Mac/Linux) atau Command Prompt / PowerShell (Windows).
  2. Ketik perintah ini lalu tekan Enter:
    python -m http.server 8000
  3. Buka browser dan ketik alamat: http://localhost:8000

Hasil Yang Diharapkan

Browser akan menampilkan daftar file/folder yang ada di komputermu. Selamat! Komputermu resmi jadi server web!

Kesalahan Yang Sering Terjadi

Ketik localhost:8000 tapi lupa belum menjalankan perintah python di terminal.

Cara Memperbaikinya

Pastikan jendela Terminal tidak ditutup dan perintah python masih aktif berjalan (jangan ditekan Ctrl+C dulu).

🎯 Mini Challenge

Coba buat satu file bernama index.html di folder latihanmu dengan isi <h1>Halo Server!</h1>, lalu jalankan server python. Apa yang berubah saat kamu buka localhost:8000?

📌 Ringkasan Modul 1

  • Server: Program komputer yang melayani permintaan data.
  • Localhost: Kata kunci untuk merujuk pada komputer tempat kita mengetik.
MODUL 02

127.0.0.1 vs 0.0.0.0 (IP Loopback & Host Binding)

Tujuan

Memahami perbedaan kritis antara IP internal 127.0.0.1 dengan 0.0.0.0 saat menyalakan server.

Penjelasan Singkat (Analogi Cermin & Pintu Pagar)

• 127.0.0.1 (Loopback Address): Ini adalah IP khusus untuk "Bicara dengan diri sendiri". Analoginya seperti kamu ngobrol di depan cermin. Hanya KAMU di laptop itu yang bisa dengar. Device lain dari luar TIDAK AKAN PERNAH bisa masuk.

• 0.0.0.0 (All Interfaces Binding): Ini artinya servermu bilang: "Buka semua pintu pagar! Saya mau mendengarkan permintaan dari mana saja—baik dari laptop ini sendiri MAUPUN dari jaringan WiFi luar!"

Diagram Sederhana

 --- Jika Server di-bind ke 127.0.0.1 ---
 Laptop Sendiri  ---> [127.0.0.1:3000] (BISA)
 HP via WiFi     ---> [127.0.0.1:3000] (DITOLAK / Connection Refused!)

 --- Jika Server di-bind ke 0.0.0.0 ---
 Laptop Sendiri  ---> [0.0.0.0:3000] (BISA via localhost)
 HP via WiFi     ---> [IP_Laptop:3000] (BISA DIARSES! 🎉)

Praktik

Mari tes perbedaan binding ini:

  1. Tes 1: Jalankan python khusus loopback (hanya laptop sendiri):
    python -m http.server 8000 --bind 127.0.0.1
  2. Tes 2: Matikan (Ctrl+C), lalu jalankan python ke semua pintu (0.0.0.0):
    python -m http.server 8000 --bind 0.0.0.0

Hasil Yang Diharapkan

Pada Tes 2 (0.0.0.0), server kamu siap menerima koneksi dari mana saja termasuk HP teman yang terhubung di WiFi yang sama!

Kesalahan Yang Sering Terjadi

Mencoba membuka http://0.0.0.0:8000 langsung di browser HP. (Ingat: 0.0.0.0 itu bukan alamat yang diketik di HP, tapi konfigurasi penangkapan di server!).

Cara Memperbaikinya

Di HP, yang diketik adalah IP Local laptopmu (seperti 192.168.1.X:8000), bukan 0.0.0.0!

🎯 Mini Challenge

Kenapa secara default developer suka pakai 127.0.0.1 saat koding? (Petunjuk: Pikirkan tentang keamanan jaringan publik!).

📌 Ringkasan Modul 2

  • 127.0.0.1 = Khusus internal laptop sendiri (Privat & Aman).
  • 0.0.0.0 = Buka akses untuk jaringan luar / WiFi.
MODUL 03

IP Local (Akses Web dari HP via 192.168.x.x)

Tujuan

Menemukan IP Local komputer dan mengakses web lokal langsung dari HP atau device lain.

Penjelasan Singkat (Analogi Alamat Rumah di Perumahan)

WiFi rumah/kantor kamu itu seperti sebuah Komplek Perumahan. Router WiFi memberikan "Nomor Rumah Local" kepada setiap device yang terhubung.

IP Local biasanya berawalan 192.168.x.x atau 10.x.x.x. Agar HP kamu bisa berkunjung ke laptopmu, HP harus tahu IP Local si laptop!

Diagram Sederhana

               [ Router WiFi Rumah ]
                         |
      +------------------+------------------+
      |                                     |
 [ Laptop Kamu ]                     [ Smartphone HP ]
 IP: 192.168.1.10                    IP: 192.168.1.25
 (Server Port 8000)                        |
      ^                                    |
      +=== Buka http://192.168.1.10:8000 ===+

Praktik (Cari IP & Akses dari HP)

  1. Pastikan HP dan Laptop terhubung ke WiFi yang SAMAA.
  2. Cari IP Laptopmu di Terminal:
    • Windows: Ketik ipconfig (Lihat di bagian IPv4 Address, misal: 192.168.1.15)
    • Mac/Linux: Ketik ifconfig atau ip a (Lihat di bagian inet under en0 / wlan0)
  3. Jalankan server dengan bind 0.0.0.0:
    python -m http.server 8000 --bind 0.0.0.0
  4. Buka Chrome/Safari di HP kamu, ketik: http://192.168.1.15:8000 (Sesuaikan dengan IP laptopmu!).

Hasil Yang Diharapkan

Tampilan website di laptopmu muncul dengan mulus di layar HP!

Kesalahan Yang Sering Terjadi

HP pakai Paket Data (Cellular 4G/5G), sedangkan Laptop pakai WiFi. Mereka tidak akan pernah bisa saling ketemu!

Cara Memperbaikinya

Matikan Paket Data HP, sambungkan HP ke WiFi yang sama dengan laptop. (Atau gunakan Hotspot HP ke Laptop!).

🎯 Mini Challenge

Coba nyalakan Hotspot di HP-mu, lalu sambungkan Laptop ke Hotspot tersebut. Berapakah IP local laptopmu sekarang? Apakah berubah?

📌 Ringkasan Modul 3

  • IP Local (192.168.x.x) adalah alamat laptopmu dalam jaringan WiFi lokal.
  • Syarat utama akses dari HP: 1 Jaringan WiFi & Server Bind 0.0.0.0.
MODUL 04

Port Server & Mengatasi Bentrok (Port in Use)

Tujuan

Memahami konsep Port (3000, 8000, 8080) dan cara menyelesaikan error "EADDRINUSE / Port already in use".

Penjelasan Singkat (Analogi Nomor Pintu / Stop Kontak)

Jika IP adalah Alamat Gedung, maka Port adalah Nomor Pintu Kamar di dalam gedung tersebut.

Satu nomor pintu hanya bisa ditempati oleh SATU aplikasi server dalam satu waktu. Jika aplikasi Node.js sudah pakai Port 3000, lalu kamu jalankan aplikasi React di Port 3000 juga, akan terjadi tabrakan!

Diagram Sederhana

 Laptop (IP: 192.168.1.10)
  +-----------------------------------+
  |  Port 80   : Server Web Default   |
  |  Port 3000 : App React / Node.js  |
  |  Port 8000 : App Laravel / Python |
  |  Port 8080 : App Vue / Java       |
  +-----------------------------------+
  *(Jika 2 aplikasi coba pakai Port 3000 = ERROR BENTROK!)*

Praktik (Mengganti Port yang Bentrok)

  1. Coba jalankan server python di port 8000:
    python -m http.server 8000
  2. Buka jendela Terminal KEDUA (jangan tutup terminal pertama), lalu ketik perintah yang sama.
  3. Lihat error yang muncul: OSError: [Errno 98] Address already in use atau port is already in use.
  4. Solusi: Ubah nomor port di terminal kedua menjadi 8081 atau 9000:
    python -m http.server 8081

Hasil Yang Diharapkan

Server kedua berjalan lancar di Port 8081 tanpa mengganggu server pertama di Port 8000!

Kesalahan Yang Sering Terjadi

Panik saat melihat error "Port already in use" dan mengira kodingan web-nya yang rusak.

Cara Memperbaikinya

Cukup ganti nomor port di command peluncuran server, atau matikan proses server lama yang masih nyangkut di background.

🎯 Mini Challenge

Port berapakah yang secara default digunakan oleh lalu lintas web HTTP standar di dunia nyata? (Petunjuk: angka 2 digit!).

📌 Ringkasan Modul 4

  • Port adalah jalur pintu masuk spesifik untuk setiap aplikasi server.
  • Satu port hanya bisa dipakai 1 aplikasi aktif. Ganti port jika terjadi konflik!
MODUL 05

Perilaku Host Binding: PHP vs Node.js vs Python

Tujuan

Memahami kenapa framework favoritmu (PHP, Node/Vite, Python) memiliki perilaku default yang berbeda-beda saat dijalankan.

Penjelasan Singkat

Tiap bahasa/tool punya filosofi bawaan:
• PHP (Artisan) & Vite (Node): Mengutamakan Keamanan Default, sehingga mengunci server hanya ke 127.0.0.1 (localhost).
• Python http.server: Mengutamakan Kemudahan Akses, langsung mengikat ke 0.0.0.0 pada versi tertentu.

Tabel Perbandingan Perintah & Kunci Binding

Framework / Tool Perintah Default Binding Default Cara Ubah Agar Buka Akses HP (0.0.0.0)
PHP (Laravel) php artisan serve 127.0.0.1:8000 php artisan serve --host=0.0.0.0
PHP (Built-in) php -S localhost:8000 127.0.0.1:8000 php -S 0.0.0.0:8000
Node.js (Vite) npm run dev 127.0.0.1:5173 npm run dev -- --host 0.0.0.0
Node.js (Express) app.listen(3000) 0.0.0.0:3000 app.listen(3000, '0.0.0.0')
Python (HTTP) python -m http.server 0.0.0.0:8000 python -m http.server 8000 --bind 0.0.0.0

Praktik (Uji Coba Perintah Framework-mu)

Pilih salah satu bahasa yang kamu pakai, jalankan perintah penyediaan akses publiknya:

# PHP Laravel php artisan serve --host=0.0.0.0 --port=8000 # Node.js (Vite React/Vue) npx vite --host 0.0.0.0 --port 3000 # Python python3 -m http.server 8000 --bind 0.0.0.0

Hasil Yang Diharapkan

Terminal akan menampilkan pesan konfirmasi: Network: http://192.168.x.x:port yang menandakan servermu siap diakses dari HP!

📌 Ringkasan Modul 5

  • Ingat kunci sakti flag: --host=0.0.0.0 atau --bind 0.0.0.0 untuk membuka akses jaringan WiFi pada framework modern!

Cheat Sheet Perintah Server Framework

Pilih bahasa favoritmu untuk melihat cara menjalankan & membuka akses IP Localnya.

🐘 PHP Server Commands

Secara default php artisan serve hanya bisa dibuka di localhost laptop sendiri.

php artisan serve
php artisan serve --host=0.0.0.0 --port=8000

💡 Native PHP: php -S 0.0.0.0:8000

🟢 Node.js & Vite Commands

Vite / Next.js membatasi akses network demi keamanan default development.

npm run dev
npm run dev -- --host 0.0.0.0

💡 Express JS: Pastikan menggunakan app.listen(3000, '0.0.0.0')

🐍 Python Server Commands

Server web praktis tanpa install library tambahan.

python -m http.server 8000 --bind 127.0.0.1
python -m http.server 8000 --bind 0.0.0.0

💡 Flask: app.run(host='0.0.0.0', port=5000)

Panduan Troubleshooting Masalah Umum

Temukan solusi instan untuk 8 masalah yang paling sering dialami pemula.

❌

1. Localhost Tidak Bisa Dibuka

Penyebab: Server belum dinyalakan atau salah mengetik port di browser.

Solusi: Cek terminalmu, pastikan proses server masih running. Pastikan menulis port dengan tanda titik dua, misal: localhost:8000 (bukan localhost 8000 atau localhost/8000).

⚠️

2. Error "Port Already in Use"

Penyebab: Ada aplikasi lain (atau terminal lama) yang masih menggunakan port tersebut.

Solusi: Ganti nomor port saat menjalankan server (contoh ganti dari 3000 ke 3001), atau matikan aplikasi lama via Task Manager / Terminal.

🛡️

3. Terhalang Windows Firewall

Penyebab: Windows Firewall memblokir koneksi masuk dari HP demi keamanan.

Solusi: Saat muncul popup Windows Defender Firewall, pilih centang pada "Private Networks" dan klik Allow Access. Atau izinkan port tersebut di Inbound Rules Firewall.

📍

4. Salah Mengeset IP Komputer

Penyebab: IP local laptop berubah karena router memberikan IP baru (DHCP), atau kamu salah melihat IP interface (misal IP VirtualBox/VPN).

Solusi: Selalu cek ulang IP terbaru pakai ipconfig / ifconfig di terminal sebelum mencoba connect dari HP.

📶

5. Tidak Satu Jaringan WiFi

Penyebab: HP menggunakan Paket Data 4G/5G atau terhubung ke SSID WiFi yang berbeda dari laptop.

Solusi: Hubungkan kedua device ke nama WiFi yang persis sama. Jika di kosan/kantor WiFi diisolasi (AP Isolation), gunakan Hotspot dari HP ke Laptop!

⏹️

6. Server Belum Running / Inactive

Penyebab: Jendela terminal tidak sengaja tertutup atau ketekan Ctrl+C yang menghentikan proses server.

Solusi: Buka terminal baru dan jalankan kembali perintah penyedia server kamu.

🔒

7. Binding Hanya Ke Localhost (127.0.0.1)

Penyebab: Server dijalankan tanpa flag host binding, sehingga menolak koneksi jaringan luar.

Solusi: Tambahkan argumen binding ke 0.0.0.0 (misal: php artisan serve --host=0.0.0.0 atau npm run dev -- --host 0.0.0.0).

🌐

8. Bingung Menggunakan IP 0.0.0.0 di Browser HP

Penyebab: Memasukkan http://0.0.0.0:8000 secara mentah-mentah di URL browser HP.

Solusi: 0.0.0.0 hanya untuk konfigurasi SERVER. Di browser HP, selalu masukkan IP Local Komputer kamu (seperti http://192.168.x.x:8000)!
