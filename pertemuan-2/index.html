PERTEMUAN 02

Rahasia IP 127.0.0.1 vs 0.0.0.0

Pahami beda IP Loopback (Bicara di Depan Cermin) vs Host Binding 0.0.0.0 (Membuka Pintu Pagar Rumah untuk Tamu WiFi)!

Mulai Praktik Binding 🚀 Lanjut Pertemuan 3 →
bash - pertemuan-2-demo

$ python -m http.server 8000 --bind 0.0.0.0

Serving HTTP on 0.0.0.0 port 8000...

➔ Binding 0.0.0.0 Aktif: Tamu WiFi Boleh Masuk! 🎉

💡 Analogi Cermin vs Pintu Pagar Rumah

🪞 127.0.0.1 (Loopback Address)

Analoginya seperti kamu ngobrol di depan cermin kamar. Hanya KAMU di laptop itu yang bisa mendengar. Device dari luar (seperti HP) TIDAK AKAN PERNAH bisa masuk.

🚪 0.0.0.0 (All Interfaces Binding)

Analoginya seperti kamu membuka pintu pagar rumah lebar-lebar. Server bilang: "Buka akses dari mana saja—baik dari laptop ini sendiri MAUPUN dari jaringan WiFi luar!"

Diagram Perbandingan ASCII

 --- Server di-bind ke 127.0.0.1 (Loopback) ---
 Laptop Sendiri  ---> [127.0.0.1:8000] (BISA BUKA)
 HP via WiFi     ---> [127.0.0.1:8000] (DITOLAK / Connection Refused!)

 --- Server di-bind ke 0.0.0.0 (Public Interfaces) ---
 Laptop Sendiri  ---> [0.0.0.0:8000]   (BISA via localhost)
 HP via WiFi     ---> [IP_Laptop:8000] (BISA DIBUKA! 🎉)

🛠️ Praktik Membandingkan Binding:

1

Uji Binding Internal (Laptop Only)

Jalankan server yang terkunci khusus internal laptop sendiri:

python -m http.server 8000 --bind 127.0.0.1
2

Uji Binding Publik (Siap Terima Tamu WiFi)

Matikan server pertama (tekan Ctrl + C), lalu uji Binding Publik di bawah:

python -m http.server 8000 --bind 0.0.0.0
