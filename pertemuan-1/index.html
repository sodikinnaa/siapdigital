Apa Itu Server & Localhost?

Langkah pertama menjadi developer sejati! Pahami bagaimana laptopmu bisa bertindak sebagai server web dalam hitungan detik tanpa perlu koneksi internet.

Mulai Praktik Sekarang 🚀 Lanjut Pertemuan 2 →

$ python -m http.server 8000

Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/)...

➔ Server Aktif di Localhost Laptopmu! 🎉

💡 Analogi Warung Makan & Localhost

Bayangkan Server itu seperti Warung Makan yang siap melayani pesanan kapan saja. Browser (Chrome/Firefox) adalah Pembeli yang datang meminta makanan (halaman web).

"Istilah localhost hanyalah nama panggilan sayang untuk 'Komputer Saya Sendiri'. Saat kamu mengetik localhost di browser, kamu sebenarnya bilang: 'Hei Chrome, tolong ambilkan halaman web yang tersimpan di laptop ini sendiri ya, tidak usah cari ke internet!'"

🛠️ Langkah Praktik Hands-On:

1

Buka Terminal / Command Prompt

Buka PowerShell di Windows atau Terminal di Mac/Linux pada folder latihanmu.

2

Jalankan Perintah Server Web 0 Setup

Ketik perintah di bawah ini lalu tekan Enter:

python -m http.server 8000
3

Buka Browser Kamu

Buka Chrome / Safari, lalu ketik alamat ini di URL bar:

http://localhost:8000
