Apa Itu Server & Localhost?

Langkah pertama menjadi developer sejati! Pahami bagaimana laptopmu bisa bertindak sebagai server web dalam hitungan detik tanpa perlu koneksi internet.

➔ Server Aktif di Localhost Laptopmu! 🎉

PENJELASAN KONSEP

Analogi Warung Makan & Localhost

Bayangkan Server itu seperti Warung Makan yang siap melayani pesanan kapan saja. Browser (Chrome/Firefox) adalah Pembeli yang datang minta makanan (halaman web).

Istilah `localhost` hanyalah nama panggilan sayang untuk "Komputer Saya Sendiri". Jadi saat kamu mengetik localhost di browser, kamu sebenarnya sedang bilang: "Hei Chrome, tolong ambilkan halaman web yang tersimpan di laptop ini sendiri ya, tidak usah cari ke internet!"

Diagram Sederhana

 [ Browser Kamu ] 
        |
  Minta: "localhost:8000"
        |
        v
 +-------------------------------------+
 | Laptop Kamu (Bertindak sbg Server)  |
 |  -> Melayani Halaman Web Latihan   |
 +-------------------------------------+

Langkah Praktik Dihands-on:

  1. Buka Terminal / Command Prompt di laptopmu.
  2. Masuk ke folder latihanmu dan jalankan perintah:
    python -m http.server 8000
  3. Buka Chrome, ketik: http://localhost:8000
