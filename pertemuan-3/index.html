Konsep Port Server & Port in Use

bash - port-error-demo

$ python -m http.server 8000

OSError: [Errno 98] Address already in use!

➔ Solusi: Ganti ke Port 8001 atau 8080! 💡

💡 Analogi Apartemen & Nomor Pintu Kamar

Jika IP Address adalah **Alamat Gedung Apartemen**, maka **Port** adalah **Nomor Pintu Kamar** di gedung tersebut.

"Satu pintu kamar tidak boleh ditempati 2 penghuni sekaligus! Jika Port 8000 sudah dipakai oleh server Python, lalu kamu mencoba menjalankan server lain di Port 8000, sistem operasi akan menolaknya dengan error 'Address Already in Use'."

Diagram Bentrok Port (Address in Use)

 [ Gedung Laptop IP: 192.168.1.15 ]
   ├── Kamar Port 8000 ➔ Python Server (Sedang Aktif)
   ├── Kamar Port 3000 ➔ Node.js Server (Sedang Aktif)
   └── Kamar Port 8080 ➔ [ KOSONG / SIAP PAKAI ]

🛠️ Praktik Simulasi Bentrok & Solusi Port:

1

Jalankan Server di Port 8000

Buka Terminal 1 lalu jalankan:

python -m http.server 8000
2

Jalankan Server Kedua di Port yang Sama (Buka Terminal Baru)

Tanpa mematikan Terminal 1, buka Terminal 2 baru dan ketik perintah yang sama di Port 8000. Amati error `Address already in use`!

3

Solusi: Pindahkan ke Port Lain yang Kosong

Di Terminal 2, ubah nomor portnya menjadi 8001 atau 8080:

python -m http.server 8080 --bind 0.0.0.0
