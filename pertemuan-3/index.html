📱 IP Local & Akses Web dari HP (192.168.x.x)

Mencari IP Local laptop dan membuka website langsung di HP via WiFi sama.

               [ Router WiFi Kampus ]
                         |
      +------------------+------------------+
      |                                     |
 [ Laptop Kamu ]                     [ Smartphone HP ]
 IP: 192.168.1.10                    IP: 192.168.1.25
 (Server Port 8000)                        |
      ^                                    |
      +=== Buka http://192.168.1.10:8000 ===+

Perintah Cek IP:

ipconfig (Windows) / ifconfig (Mac)
