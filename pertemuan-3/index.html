IP Local (192.168.x.x) & Akses Web dari HP

Temukan IP Local laptopmu dan buka website buatanmu langsung dari layar Smartphone teman via jaringan WiFi lokal!

PENJELASAN KONSEP

Analogi Alamat Perumahan WiFi

WiFi rumah/sekolah kamu itu seperti sebuah Komplek Perumahan. Router WiFi memberikan "Nomor Rumah Local" (IP Local berawalan 192.168.x.x atau 10.x.x.x) kepada setiap device yang terhubung.

Agar HP teman bisa berkunjung ke web laptopmu, HP harus tahu IP Local si laptop!

Diagram Jaringan ASCII

               [ Router WiFi Lokal ]
                         |
      +------------------+------------------+
      |                                     |
 [ Laptop Kamu ]                     [ Smartphone HP ]
 IP: 192.168.1.15                    IP: 192.168.1.25
 (Server Port 8000)                        |
      ^                                    |
      +=== Buka http://192.168.1.15:8000 ===+

Praktik (Cari IP & Akses HP):

  1. Pastikan HP dan Laptop terhubung ke **WiFi yang SAMA**.
  2. Cari IP Laptopmu di Terminal:
    ipconfig (Windows) ATAU ifconfig (Mac/Linux)
  3. Jalankan server dengan bind `0.0.0.0`:
    python -m http.server 8000 --bind 0.0.0.0
  4. Buka Chrome di HP teman, ketik: http://192.168.1.15:8000 *(ganti 192.168.1.15 sesuai IP laptopmu)*.
