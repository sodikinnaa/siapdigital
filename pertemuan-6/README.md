# 🎯 Pertemuan 6: Evaluasi, Quiz Interaktif & Troubleshooting Mandiri

## 🎯 Tujuan Pembelajaran
Mahasiswa mampu mendiagnosis dan memperbaiki kendala jaringan server secara mandiri serta menyelesaikan Quiz Evaluasi perkuliahan.

---

## 📋 Checklist Mandiri Mahasiswa
- [ ] Laptop dan HP terhubung ke **WiFi yang SAMA**.
- [ ] Sudah cek **IP Local Laptop** via `ipconfig`.
- [ ] Server di-bind ke **`0.0.0.0`**.
- [ ] Jendela terminal **TIDAK ditutup**.
- [ ] Menggunakan port di URL HP (seperti `http://192.168.1.15:8000`).
