PERTEMUAN 05

Bedah Perilaku Framework Popular

Mengapa Laravel, Vite Node.js, dan Python memiliki perintah flag host binding yang berbeda-beda? Yuk bedah satu per satu!

Pelajari Cheat Sheet 🚀 Lanjut Pertemuan 6 →
bash - framework-cheat

$ npm run dev -- --host 0.0.0.0

➜ Network: http://192.168.1.15:5173/

➔ Vite Server Buka Akses HP! 🎉

💡 Mengapa Perilaku Framework Berbeda-beda?

Secara default, demi **alasan keamanan (Security Default)**, hampir semua framework web populer (Laravel, Vite, Next.js, Express) mengunci server-nya di 127.0.0.1 (Internal Laptop Only).

"Setiap framework memiliki sintaks flag CLI yang berbeda untuk membuka kuncinya ke 0.0.0.0. Jika kamu menggunakan Laravel, gunakan --host=0.0.0.0. Jika menggunakan Vite, tambahkan -- --host 0.0.0.0."

🛠️ Cheat Sheet Perintah Framework:

🐘

PHP & Laravel Framework

Perintah bawaan vs Perintah Buka Akses WiFi HP:

php artisan serve --host=0.0.0.0 --port=8000

*(Atau PHP Native: php -S 0.0.0.0:8000)*

🟢

Node.js & Vite / Next.js

Buka akses network untuk dev server Vite:

npm run dev -- --host 0.0.0.0
🐍

Python HTTP Server

Buka akses server HTTP Python:

python -m http.server 8000 --bind 0.0.0.0
