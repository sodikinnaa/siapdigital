PERTEMUAN 05

Cara Buka Akses Server di Tools Favoritmu

Punya kodingan di Laravel, React/Vite, atau Python? Yuk lihat perintah simpel 1 baris untuk membuka akses servernya ke HP!

Lihat Perintah Simpel 🚀 Lanjut Pertemuan 6 →
bash - cheat-sheet-simpel

$ npm run dev -- --host 0.0.0.0

➜ Network HP: http://192.168.1.15:5173/

➔ Perintah 1 Baris Langsung Jalan! 🎉

💡 Inti Rahasianya Sangat Simpel!

Setiap tools koding (seperti Laravel, React/Vite, atau Python) punya tombol atau kunci perintah yang beda-beda. Tapi **TUJUANNYA SAMA BANGET**: menambahkan kode 0.0.0.0 agar pintu servernya terbuka untuk HP temanmu!

"Cukup hapal 1 baris perintah sesuai tool favorit yang sedang kamu pakai sehari-hari!"

🛠️ Pilih Perintah Sesuai Tool Kamu:

🐘

Kodingan PHP / Laravel

Ketik perintah ini di terminal project-mu:

php artisan serve --host=0.0.0.0

*(Atau PHP biasa tanpa Laravel: php -S 0.0.0.0:8000)*

🟢

Kodingan React / Vue / Vite

Ketik perintah ini di terminal project-mu:

npm run dev -- --host 0.0.0.0
🐍

Kodingan HTML / Python

Ketik perintah ini di terminal foldermu:

python -m http.server 8000 --bind 0.0.0.0

🎯 Mini Challenge Pertemuan 5

Coba jalankan 1 perintah di atas sesuai tool favoritmu. Apakah alamat IP local laptopmu (seperti 192.168.x.x) muncul di layar terminal?
