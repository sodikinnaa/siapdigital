CHEAT SHEET PERINTAH

Perbandingan Command Laravel, Vite & Python

Tiap bahasa/tool punya filosofi bawaan:
• PHP (Artisan) & Vite (Node): Mengutamakan Keamanan Default, sehingga mengunci server hanya ke 127.0.0.1 (localhost).
• Python http.server: Mengutamakan Kemudahan Akses, langsung mengikat ke 0.0.0.0 pada versi tertentu.

Framework / Tool Perintah Default Binding Default Cara Ubah Agar Buka Akses HP (0.0.0.0)
PHP (Laravel) php artisan serve 127.0.0.1:8000 php artisan serve --host=0.0.0.0
Node.js (Vite) npm run dev 127.0.0.1:5173 npm run dev -- --host 0.0.0.0
Python (HTTP) python -m http.server 0.0.0.0:8000 python -m http.server 8000 --bind 0.0.0.0

Praktik Menjalankan Akses Jaringan:

# PHP Laravel php artisan serve --host=0.0.0.0 --port=8000 # Node.js (Vite) npm run dev -- --host 0.0.0.0 # Python python -m http.server 8000 --bind 0.0.0.0
