PERTEMUAN 04

Konsep Port Server & Mengatasi Bentrok

Pahami nomor pintu kamar server (3000, 8000, 8080) dan cara menyelesaikan error misterius "Address already in use / Port in use"!

Solusi Port Bentrok 🚀 Lanjut Pertemuan 5 →
bash - pertemuan-4-demo

$ python -m http.server 8000

OSError: [Errno 98] Address already in use!

➔ Solusi: Ganti ke `python -m http.server 8081` 🎉

PENJELASAN KONSEP

Analogi Nomor Pintu Kamar Gedung

Jika IP adalah Alamat Gedung, maka Port adalah Nomor Pintu Kamar di dalam gedung tersebut.

Satu nomor pintu hanya bisa ditempati oleh SATU aplikasi server dalam satu waktu. Jika aplikasi Node.js sudah pakai Port 3000, lalu kamu jalankan aplikasi React di Port 3000 juga, akan terjadi tabrakan!

Diagram Arsitektur Port ASCII

 Laptop (IP: 192.168.1.15)
  +-----------------------------------+
  |  Port 80   : Server Web Default   |
  |  Port 3000 : App React / Node.js  |
  |  Port 8000 : App Laravel / Python |
  |  Port 8080 : App Vue / Java       |
  +-----------------------------------+
  *(Jika 2 aplikasi coba pakai Port 3000 = BENTROK/ERROR!)*

Praktik Memancing & Memperbaiki Error Bentrok:

  1. Jalankan server di Terminal 1:
    python -m http.server 8000
  2. Buka Terminal 2 (jangan tutup terminal 1), ketik perintah yang sama untuk memancing error:
    python -m http.server 8000
  3. Lihat error: OSError: Address already in use.
  4. Solusi: Pindahkan server kedua ke port 8081:
    python -m http.server 8081
